# 用户手册

## 首次运行

在项目根目录安装 `requirements.txt` 中的依赖并执行 `python -m backend.app`。访问 <http://127.0.0.1:5000>。首次启动自动建立数据库和课堂样例。

| 角色 | 用户名 | 密码 |
| --- | --- | --- |
| 管理员 | `admin` | `admin12345` |
| 教师 | `teacher` | `teacher12345` |
| 学生 | `student` | `student12345` |

示例账号仅供本地演示，部署到共享环境前应更换密码、停用样例账号并设置安全的 JWT 密钥。

## 学生

1. 用示例学生登录，或创建学生账号。
2. 管理员安排名单后，课堂会出现在“正在参与的课堂”选择框中。
3. 课堂状态为进行中且当前时间位于开课/结束时间内时，选择一个情绪表情完成记录。
4. “我的课堂记录”显示最近反馈；“我的历史”显示完整个人记录。
5. 在个人资料流程中使用当前密码修改密码；旧登录令牌会立刻失效。

## 教师

新教师点击“创建账号”，注册身份选择“教师”，填写姓名、用户名、密码和管理员提供的教师邀请码。注册成功后自动登录；课程由管理员创建并关联到教师账号。

登录后进入课堂情绪看板，课堂选择框只列出本人授课内容。总数、积极/专注比例、趋势和最新记录均为所选课堂近60分钟的数据，按五分钟分桶。课程、班级及日期筛选用于历史分布和课次统计，历史分布显示筛选总数，实时推送不会覆盖它。实时连接不可用时自动轮询；账号停用、改密、权限变化或令牌过期后，既有连接在下一次推送前停止。

课堂情绪是群体教学反馈，不代表任何学生的个人状态或能力。

## 管理员

- 首任管理员在未初始化的数据库中使用部署时设置的初始化密钥注册；后续管理员使用现有管理员生成的管理员邀请码注册。选择“管理员”身份后，在邀请码字段填写相应凭据。
- “数据概览”按统计课程、统计班级和起止日期筛选，点击“更新统计”查看分布、每日情绪趋势、课程与班级对比图；没有记录时展示空状态。
- “AI 实时识别”选择开放课次，点击“开启摄像头并识别”并允许权限，查看实时画面、对应emoji、置信度、采样图和入库状态；课次ID直接显示。停止、切页或退出会释放摄像头，见 [网页指南](ai-web-monitor.md)。
- 同页“课堂实时看板”可选择任意课堂，查看近一小时反馈、积极/专注比例、已安排人数、趋势与最新记录。该选择独立于历史统计筛选；实时推送不可用时自动轮询。
- “课堂排课”先创建课程和课堂课次，再选择课次并勾选启用学生后保存名单。
- “用户管理”选择邀请身份和有效期，点击“生成一次性邀请码”，复制显示的代码单独提供给受邀人。邀请码只显示一次、按角色生效、过期或使用后失效。此页也可调整角色或停用账号。
- “记录与导出”按课程、班级、课堂、日期和记录来源筛选；导出按钮下载可在电子表格中打开的 UTF-8 CSV。
- API 文档可从右上角或 `/api/docs` 打开。

## AI 摄像头服务

AI接入默认未启用。执行 `python -m scripts.setup_local` 创建本地配置，在 `.env` 填写 `AI_API_KEY`、模型地址与模型名；后端与AI进程会读取同一服务令牌。具体启动、真实课次ID、摄像头编号、单次验证及脱敏证据见 [AI接入指南](ai-integration.md)，录屏见 [视频指南](demo-script.md)。

网页模式只需启动后端，在管理员“AI 实时识别”开启浏览器摄像头，不必运行独立AI进程；原进程占用设备时先停止。通过localhost、127.0.0.1或HTTPS访问，开启的是浏览器所在电脑的摄像头。

OpenCV 先在本地检测人脸，再把最多 8 个脸部裁片组成的拼图发给模型 API；原始帧和拼图不会写入磁盘。脸部裁片仍是敏感生物特征数据，且会发到外部模型服务。开始前应告知课堂参与者并取得必要授权。AI 结果只作聚合观察，不作个人高影响决定。

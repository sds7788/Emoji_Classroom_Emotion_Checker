# 需求规格说明书

## 目标与范围

系统把课堂情绪反馈作为教学过程的补充观察信息。学生可以在课堂中主动选择表情，教师查看本人课程的聚合反馈，管理员安排课堂名单并维护数据。可选 AI 进程分析摄像头采样帧，将置信度达标的匿名汇总结果写入课堂记录。

系统不用于个人学习能力评估、纪律判定、成绩评定或医疗诊断。AI 预测只能作为需要教师结合其他信息解释的课堂参考。

## 用户与权限

| 角色 | 核心权限 | 数据范围 |
| --- | --- | --- |
| 学生 | 自助注册/登录、修改密码、查看排课、提交六类情绪、查询个人历史 | 本人已排课课堂和本人手动记录 |
| 教师 | 登录、查看授课课堂、实时看板、课程/班级/时间筛选统计 | 自己负责的课程和课堂 |
| 管理员 | 查看用户和全部记录、调整角色/账号状态、建课程和课次、安排学生、统计和 CSV 导出 | 全部系统数据 |
| AI 服务 | 通过独立共享令牌提交匿名预测结果 | 只提交指定课堂的 AI 记录，无用户管理权限 |

公开注册只能创建学生账号。教师和管理员由管理员从用户管理中授予角色。

## 功能需求与验收

| 编号 | 功能需求 | 验收方式 |
| --- | --- | --- |
| FR-01 | 用户使用用户名和密码注册/登录；密码使用 bcrypt 盐哈希保存 | 注册后可登录；数据库不包含明文密码 |
| FR-02 | 修改密码时验证旧密码并吊销旧 JWT | 旧令牌访问当前用户接口返回 401 |
| FR-03 | 学生只能查看已安排给本人的课堂 | 未排课课堂不可见且无法提交记录 |
| FR-04 | 学生在开放课堂记录开心、困惑、无聊、低落、专注、兴奋之一 | 越枚举值被拒绝；记录有时间、来源 MANUAL 和课堂 ID |
| FR-05 | 学生只能读取自己的手动记录 | 使用其他用户 ID 筛选也不会读取他人记录 |
| FR-06 | 教师查看本人课堂历史、分布、趋势和最新反馈 | 访问其他教师课堂返回 403 |
| FR-07 | 管理员维护用户角色和停用状态 | 未认证返回 401，非管理员返回 403 |
| FR-08 | 管理员创建课程/课堂并按课次替换学生名单 | 排课只接受启用状态的学生；名单唯一 |
| FR-09 | 管理员按课堂、来源、课程或时间筛选记录并导出 CSV | CSV 为 UTF-8 BOM，公式开头字符被转义，导出操作写审计日志 |
| FR-10 | AI 服务用独立令牌提交情绪和置信度 | 错误令牌拒绝；低于配置阈值的结果不入库 |
| FR-11 | AI 记录匿名，不关联学生用户 ID | AI 记录的 `user_id` 为空，`source=AI` 并存置信度 |
| FR-12 | 教师看板实时聚合课堂反馈 | WebSocket 每 5 秒推送；前端断线后降级为 10 秒 HTTP 轮询 |
| FR-13 | 系统提供 REST/JSON、统一响应、OpenAPI 文档 | API 响应含 `code/message/data`，Swagger UI 可访问 |

## 非功能需求

- 权限由服务端校验；参数化 SQL；密码哈希；短时 JWT；改密后令牌版本失效。
- AI 摄像头原始帧不保存到磁盘或数据库；通过外部模型推理时图像会发给配置的 API 服务。
- 数据库使用外键、唯一约束、枚举 `CHECK` 和查询索引。
- 页面支持桌面和窄屏浏览器；情绪选择需可见名称、可键盘聚焦。
- 空白模型凭据不得阻塞手动记录、教师看板和管理员功能。

## 范围外

Android 原生客户端、消息队列、MCP 工具封装、匿名群体问卷模式、HTTPS 证书和学校单点登录不包含在当前可运行基线中；可在后续迭代扩展。

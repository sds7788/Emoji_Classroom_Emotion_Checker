# 5～8 分钟演示视频录制指南

建议成片 7分30秒。目前提供分镜与验收截图，尚未生成最终演示视频；截图不能替代带讲解的实际操作录像。

## 录制前

1. 按 [AI接入指南](ai-integration.md) 安装、执行 `python -m scripts.setup_local` 并在本机填写配置，启动 `python -m backend.app`。这里的python应使用安装依赖的虚拟环境解释器。
2. 管理员创建当天开放课次，结束时间至少留30分钟，安排学生student，记下真实课次ID；不要沿用过期的种子课次。
3. 用三个独立浏览器配置文件或三个不同浏览器分别登录admin、teacher、student，密码为用户名加12345。同一浏览器普通标签页共享localStorage，不能稳定保持三种身份；普通与无痕也只有两组独立会话。
4. 在管理员“AI 实时识别”选开放课次，开启摄像头并允许权限，确认显示真实emoji、置信度及入库ID。取得参与者同意，只让镜头面向演示者；失败时排错，不用模拟结果冒充实测。CLI方式仍可使用，先停止网页采集避免占用设备。
5. 执行 `python -m unittest discover -s tests -v` 保留实际结果；本轮51项通过。重现浏览器验收需安装requirements-dev.txt和Chromium，再运行 `python -m scripts.acceptance`，证据写入artifacts/acceptance。
6. 打开三角色页面、AI终端、测试结果、架构图和/api/docs。关闭.env编辑器与含密钥的终端历史，终端字号调至18～20px，关闭通知。

## OBS操作

从 [OBS官网](https://obsproject.com/) 安装，运行自动配置向导并选择录制为主。新建“课堂演示”场景，添加“显示器采集”捕获浏览器与终端切换，设置麦克风并检查音量；只录单窗口时用“窗口采集”。参见 [官方快速入门](https://obsproject.com/kb/quick-start-guide/)。

建议1920×1080、30fps、H.264与AAC音频。先试录20秒，回放检查声音、文字和窗口切换。关闭多余桌面音频，避免通知声及回声。

格式选MKV，结束后“文件→录像转封装”转成MP4。OBS官方说明MKV可降低录制中断损坏整段视频的风险，并内置MP4转封装，见 [录制输出指南](https://obsproject.com/kb/standard-recording-output-guide)。OBS不要同时添加同一摄像头来源，以免占用AI设备。

点击“开始录制”，按下表操作，结束后“停止录制”。成片可先命名“演示视频-组号.mp4”，提交时再按指导书调整。

## 分镜及讲解

| 时间 | 操作画面 | 讲解示例 |
| --- | --- | --- |
| 0:00～0:35 | 登录页和架构图 | “系统包含学生、教师和管理员。学生主动反馈，教师观察本人课堂，管理员排课与统计；Flask处理接口，SQLite保存数据，AI独立运行。” |
| 0:35～1:30 | 管理员创建当天课次，选开放记录，勾选学生并保存；课程可提前创建 | “课程与课堂课次分别管理。学生必须在名单里，且课堂开放、时间有效，才能提交。” |
| 1:30～2:20 | 学生选同一课次提交专注，查看个人历史 | “六种表情由学生主动选择。系统记录时间、课次及MANUAL来源，学生只看自己的历史。” |
| 2:20～3:15 | 教师选课次，学生再提交开心，切回教师等待推送；筛选昨天历史 | “指标和趋势取所选课堂近60分钟，WebSocket自动更新。日期筛选作用于历史分布，实时消息不会改写历史范围。” |
| 3:15～4:15 | 管理员按课程/班级/日期筛选，展示对比与独立实时看板 | “管理端支持多维统计；历史筛选与实时课堂独立，零记录显示空状态。” |
| 4:15～5:30 | 管理员进入“AI 实时识别”，选课次、开启摄像头，展示视频、emoji、置信度和对应采样图，然后停止 | “网页持续预览并定时采样，后端检测人脸，将裁片拼图发给视觉模型。结果对应缩略图与采样时间，低于阈值不入库，达标匿名保存。” |
| 5:30～6:15 | 管理员记录查询选课次及AI来源，查看匿名与置信度，导出并打开CSV | “AI结果不关联学生账号，来源与人工区分。CSV带UTF-8 BOM并转义公式前缀，每次最多导出最新500条。” |
| 6:15～7:00 | 展示测试输出、验收记录和/api/docs | “51项测试覆盖Service、权限、SQL注入、弱密码、CSV和AI模拟链路；真实浏览器也验证排课到导出及连接建立后的撤权。” |
| 7:00～7:30 | 局限说明及系统页面 | “光线、遮挡和模型偏差会影响分类，只作为课堂聚合参考。图像不落盘，但外发裁片仍需授权；本次实测结论以日志和页面记录为准。” |

如果真实AI未成功，明确说“当前仅验证模拟链路，真实模型/摄像头验收尚未完成”，保留失败原因并将视频标注阶段演示。不要为了录制随意降低阈值制造成功。

## 录后核对

- 5～8分钟，声音清楚、文字可读，包含学生提交、教师查看、管理员排课/筛选/导出和AI入库过程。
- AI日志的课次、记录ID及置信度与页面/CSV对应，区分真实实测与模拟测试。
- 无API Key、JWT、共享令牌、有效邀请码或未经同意的他人人脸。
- 回放MP4，在 [验收记录](acceptance-record.md) 填写视频路径、时长、真实AI与目标电脑结论。按要求暂不生成最终压缩包。

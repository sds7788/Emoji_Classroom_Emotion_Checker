# 现场演示流程

建议时长 7-8 分钟，演示前启动后端并确认示例数据库与账号可用。

| 时间 | 操作 | 讲解要点 |
| --- | --- | --- |
| 0:00-0:45 | 打开登录页与 `/api/docs` | 说明学生/教师/管理员角色、API 和 SQLite 结构 |
| 0:45-1:45 | 管理员打开排课页，查看示例课程和名单 | 展示课程、课堂课次、名单安排 |
| 1:45-2:40 | 学生登录，在进行中课堂记录一个表情 | 展示可选状态、手动来源和个人记录 |
| 2:40-3:45 | 教师登录打开实时看板 | 观察 WebSocket 数据、情绪分布和趋势更新 |
| 3:45-4:45 | 管理员打开数据概览，筛选课程、班级和日期，再选择实时课堂 | 展示每日趋势、情绪分布、课程/班级对比和实时反馈；说明历史筛选与实时范围独立 |
| 4:45-5:40 | 管理员在用户管理生成教师邀请码，使用新账号注册；随后展示记录导出 | 展示角色邀请码、自动进入对应页面、来源/课堂筛选和 UTF-8 CSV；避免公开展示仍有效的邀请码 |
| 5:40-6:35 | 使用测试或 Postman 调 AI 入库接口 | 展示独立令牌、低阈值丢弃与匿名记录 |
| 6:35-7:40 | 展示 11 项测试结果、数据库和 AI 局限性 | 说明空库首任管理员初始化流程；摄像头 API 未填时核心仍可运行；强调不做个人高影响判断 |

真实摄像头演示需要预先配置 `AI_API_KEY`、`AI_SERVICE_TOKEN`、模型地址与摄像头权限，并事先告知参与者。不要在公开视频中展示密钥。
